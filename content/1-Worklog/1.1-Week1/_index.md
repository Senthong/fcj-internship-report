### Week 1 Objectives:

* Connect and get acquainted with members of First Cloud AI Journey; review internship rules and reporting format.

### Week 1 Achievements:

* Understood what AWS is and mastered the basic service groups:
  * Compute
  * Storage
  * Networking
  * Database

* Successfully created and configured an AWS Free Tier account.

* Became familiar with the AWS Management Console and learned how to find, access, and use services via the web interface.

* Installed and configured AWS CLI on the computer, including:
  * Access Key
  * Secret Key
  * Default Region

* Used AWS CLI to perform basic operations such as:
  * Check account & configuration information
  * Retrieve the list of regions
  * View EC2 service
  * Create and manage key pairs
  * Check information about running services

* Launched an EC2 instance, connected via SSH, and attached an EBS volume as a hands-on exercise.

* Acquired the ability to connect between the web interface and CLI to manage AWS resources in parallel.

* Confirmed the graduation topic: building an end-to-end data pipeline for e-commerce analytics on AWS, using the Olist Brazilian E-Commerce public dataset (100k+ orders, 2016–2018).
