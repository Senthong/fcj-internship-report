## Overview

This is the core section of the workshop, where you will build the end-to-end ELT pipeline. You will implement the **Staging** and **Data Mart** layers using dbt, perform data quality validation, and orchestrate the entire workflow with Apache Airflow.

By the end of this section, you will have a fully automated data pipeline capable of extracting, loading, transforming, and validating data in Amazon Redshift.
