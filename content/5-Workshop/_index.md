# Building an E-Commerce Data Pipeline with Airflow, dbt & Amazon Redshift

### Overview
This workshop guides you through building an end-to-end **Modern Data Stack (MDS)**. You will learn how to extract e-commerce transaction data, store it in Amazon S3, load it into an Amazon Redshift data warehouse, and transform the data using dbt Core, all orchestrated automatically by Apache Airflow.
